## 1. Supply-Chain Trust Chain Topology

The software delivery lifecycle of **Between Us** spans development tools, external code dependencies, CI/CD automation, and deployment environments.

```
[ Developer ]
      │
      ├─► AI Assistance (Antigravity) ──> Human Code Review & Validation
      │
      ▼
[ Git Repository (GitHub) ]
      │
      ▼ (Triggers Pull Request / Main Push)
[ CI/CD Pipeline (GitHub Actions) ]
      │
      ├─► 1. Run Automated Security Unit Tests & State Machine Tests
      ├─► 2. Run npm audit --audit-level=high (Verify Package Lock)
      ├─► 3. Run Static Code Analysis & CSP Header Verification
      │
      ▼ (Passes Security Checks)
[ Production Deployment (Vercel Serverless / VPS Ansible) ]
```

## 2. AI-Generated Code Trust Policy

```
+-----------------------------------------------------------------------------------+
| MANDATORY POLICY: AI-GENERATED CODE IS UNTRUSTED UNTIL HUMAN-REVIEWED             |
|                                                                                   |

| trusted or merged into production without explicit human engineering review.       |
|                                                                                   |

| 2. Must be manually reviewed for subtle side-channel leaks, improper fallback      |

| 3. Must strictly conform to Phase 01 & Phase 02 security invariants.              |
+-----------------------------------------------------------------------------------+
```

## 3. Dependency & Package Verification Rules

1. **Minimal Dependency Policy**: External npm packages are limited strictly to core platform requirements (React, Next.js, Tailwind CSS, `ws` for Node.js). Lightweight native Web APIs (Web Crypto API, native WebSockets, native WebRTC) are used in place of heavy third-party utility libraries.
2. **Lockfile Pinning (`package-lock.json`)**: All dependency versions, sub-dependencies, and SHA-512 integrity hashes must be explicitly pinned. `npm install` in CI/CD is executed exclusively via `npm ci`.
3. **Automated Vulnerability Scanning**: GitHub Dependabot and `npm audit` run on every pull request. Builds fail automatically if high or critical vulnerabilities exist.
